# **App Name**: BotLife

## Core Features:

- AI Bot Controller: Simulate bot actions (harvest, build, defend) based on environment and learned priorities, using a simple decision-making tool.
- Status Overlay: Display bot status (health, hunger, role) and basic settlement metrics via a simple in-game overlay.
- Minecraft Interface: Implement basic bot movement, block interaction, and resource management within the Minecraft world.

## Style Guidelines:

- Use earthy tones: browns, greens, and grays to blend with the Minecraft environment.
- Accent color: Gold (#FFD700) to highlight important UI elements or bot status indicators.
- Keep the UI simple and unobtrusive, providing only essential information to the player.
- Use clear and recognizable icons to represent bot roles and resources.
